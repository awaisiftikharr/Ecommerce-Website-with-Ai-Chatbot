# SmartFinds.pk - AI-Powered E-commerce Store
### Final Year Project by Awais Iftikhar

## Project Overview
This is an intelligent e-commerce platform that uses Artificial Intelligence to enhance the user experience.
* **Backend:** Django 5.0 (Python)
* **AI Engine:** TF-IDF Algorithm (Content-Based Filtering)
* **Database:** SQLite

## Features
1. **AI Recommendations:** Automatically suggests products based on description similarity.
2. **Chatbot:** Rule-based NLP bot for price and stock queries.
3. **Smart Search:** Real-time filtering.
4. **Cart & Checkout:** Dynamic cart management with payment simulation.
